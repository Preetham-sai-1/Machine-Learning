# Student Academic Performance Prediction using Linear Regression

## Objective
Predict student exam scores using machine learning based on factors such as:

- Gender
- Hours Studied
- Attendance
- Tutoring
- Region
- Parent Education

---

## Dataset
Dataset: SAP-4000.csv

Target Variable:
Exam_Score

---

- Python
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab
